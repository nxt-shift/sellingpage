# Button

Shift's primary action button — industrial type, hard borders. Use one `accent` button per screen for the hero CTA; everything else is `primary`, `outline`, or `ghost`.

```jsx
<Button variant="accent" size="lg">Join the waitlist</Button>
<Button variant="primary">Post a shift</Button>
<Button variant="outline">Learn more</Button>
<Button variant="ghost" size="sm">Cancel</Button>
```

Sizes: `sm` 32px · `md` 40px · `lg` 48px · `xl` 60px (hero).

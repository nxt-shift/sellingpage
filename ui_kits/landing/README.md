# Landing — Shift waitlist page

A single-page pre-launch landing for Shift. Composes the design system primitives (`Button`, `Input`, `Card`, `Badge`, `SectorChip`, `ReliabilityScore`, `Stat`, `FiableStamp`, `HazardDivider`) — does not invent new visuals.

Sections (in scroll order):
1. **Nav** — sticky, FR/EN toggle, accent CTA
2. **Hero** — `fiable.` headline + inline shift-request card preview
3. **Problem** — three columns from the research doc
4. **HowItWorks** — three actors + the 8-step worker flow + payment split
5. **Sectors** — the seasonal complementary calendar (A/B/blank cells)
6. **WhyNow** — Quebec stats, on dark ink
7. **Waitlist** — role + sector + email/phone, with success state
8. **CompanyFooter** — manifest of address, links, badges

Copy is French-first (Quebec market). All assets pulled from `../../assets/`.
